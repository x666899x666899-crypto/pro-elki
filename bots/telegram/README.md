# Telegram-бот для покупателей

Бот в Telegram. Он помогает покупателю, но не становится вторым магазином со своим складом и своими заказами.

## Что делает бот

- Консультирует покупателя по новогодним товарам.
- Ищет товары в общей базе и показывает название, цену и наличие.
- Помогает с уже созданным заказом: статус, состав, доставка.
- Присылает уведомления, когда статус заказа меняется.
- Передаёт диалог менеджеру, если бот не может помочь сам.

Товары, цены, остатки и заказы бот читает из общей базы. Новые заказы, если они появятся в боте, записываются туда же, одним экземпляром.

Акции и специальные предложения сайта остаются правилами сайта. Бот не заводит для них отдельный прайс.

## Сейчас

Бот для покупателей создан: `@proelki03bot`. Это не канал `t.me/proproelki`. Ключ лежит только в файле `.env` рядом с программой, не в текстовых документах. Старый ключ из чата Telegram уже не принимает. Пока в `.env` нет нового ключа, бот молчит.

Программа отвечает по [SCENARIO.md](SCENARIO.md): приветствие, адрес, доставка, ссылка на сайт, передача Валентине. Цену берёт из листа Google-таблицы, имя листа в `.env`, строка `SHEET_NAME`. Другие листы не читает. 31 октября 2026 ссылки на таблицу в проекте не было, поэтому цены ещё не подключены.

Пока программа запущена на этом компьютере, бот отвечает. Компьютер выключен или спит — бот снова молчит. Отдельный сервер, который работает всегда, ещё не выбран.
