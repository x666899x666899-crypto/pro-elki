# Интернет-магазин

Публичный сайт на Tilda. Покупатель выбирает новогодние товары и оформляет заказ сам, без обязательной переписки с менеджером. В этой папке лежат требования, а не самописный магазин.

## Что делает сайт

- Показывает каталог, категории, фотографии, цены и остатки.
- Даёт положить товар в корзину и оформить заказ.
- Принимает онлайн-оплату и собирает данные для доставки.
- Показывает скидки, акции и специальные предложения. Эти предложения действуют на сайте.
- Берёт товары, цены, остатки и заказы из общей базы через интеграции. Сайт не ведёт свой отдельный склад и свой отдельный список заказов.

## Что остаётся соседним компонентам

- Консультация в переписке, уведомления и передача диалога менеджеру — боты Telegram и MAX.
- Правка товаров, заказов, клиентов, остатков и акций — админка.
- Хранение данных — база.
- Связь с оплатой, доставкой и таблицами Google — интеграции.
